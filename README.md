# 小车大冒险 🚗

一个给 5-6 岁小朋友玩的网页版赛车小游戏。无需安装，打开即玩。

## 玩法

- 小车自动向前开，按住屏幕下方的 **◀ / ▶** 大按钮左右移动（也可以直接用手指拖动小车，或用键盘方向键 / A、D）。
- 收集路上的 ⭐ 星星，躲开 🚧 路障。撞到路障不会失败，只是会减速并弹开，永远可以继续玩。
- 开到 🏁 终点就通关，会撒彩带庆祝，并显示收集到的星星数量。

## 选车

开始前可以在车库里挑一辆车：法拉利 488、兰博基尼 Aventador、奔驰大 G、宝马 i8、奥迪 R8、大众甲壳虫、特斯拉 Cybertruck、丰田 86。每辆车有不同颜色和造型，车头带着车标，通关后会显示车型名，还可以「换一辆车」。

车标为简化手绘示意图，商标归各品牌所有，本项目仅用于小朋友认识车辆，不作商业用途。

## 给家长的设计说明

- 没有失败、没有倒计时、没有广告，撞车只有轻微的"呀"提示。
- 按钮和判定框都刻意放大，适合小手操作。
- 声音可以一键静音，静音设置会被记住。
- 自动适配手机、平板和电脑：竖屏横屏都行，刘海屏安全区域已处理，选过的车会被记住。
- 单文件 `index.html`，不依赖任何外部资源，可离线运行。

## 本地运行

直接双击 `index.html`，或在目录下启动一个静态服务器：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。
