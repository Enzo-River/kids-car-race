# 小车大冒险 🚗

一个给 5-6 岁小朋友玩的网页版赛车小游戏。无需安装，打开即玩，可添加到手机主屏幕全屏、离线玩。

## 玩法

- 小车自动向前开，按住屏幕下方的 **◀ / ▶** 大按钮左右移动（也可以直接用手指拖动小车，或用键盘方向键 / A、D）。
- 收集路上的汉字卡片，吃掉时会朗读这个字的读音；多音字按最常用的读音读（例如「长」读 cháng）。躲开 🚧 路障和其他车辆。撞到不会失败，只是会减速并弹开，永远可以继续玩。
- 收集够本关要求的汉字就通关，会撒彩带庆祝，并给出 1-3 颗星的评价。左上角会显示刚吃到的字和已经收集的 ⭐ 数量，每吃一个都会跳动加一。
- 连续吃到汉字时音高会一级级升高，连击越多越"唱"得高。

## 每日小目标

开始页会显示「今日新字 X/5」，当天第一次学到的新字会累计，集满 5 个显示完成。记录只存在本机。

## 两种玩法

- **收集汉字**：路上不断出现汉字卡片，吃到就学一个，目标是收集够本关要求的数量。
- **听音选字**：先听到一个字的读音，再在路上的 3 张卡片里找出对应的字。三张牌会错开、逐个到达，题目期间车速会稍微放慢；选错只消失那一张并重播读音，不会扣分。

## 识字内容

默认 56 个汉字，每关只出其中的 12 个，按关卡轮换，一局内不会重复：前、包、可、后、今、方、平、么、间、升、众、林、吧、呀、比、友、又、长、中、本、布、会、瓜、禾、怎、回、告、森、明、呢、啦、朋、飞、公、毛、兴、年、正、广、什、没、问、从、男、吗、啊、米、船、车、雨、水、云、雪、冬、冷、风。

其中雨、水、云、雪、冬、冷、风会和当前天气联动：下雨天更容易遇到「雨、水、云」，下雪天会遇到「雪、冬、冷」，大风天会遇到「风」。

每局开始都会重新洗牌；吃到的字会进入「我认识的字」，可以随时点开重听。

## 关卡与赛道

每通关一次可以点「下一关」，赛道风景依次轮换：城市 → 沙漠 → 雪地 → 海边 → 夜晚 → 雨天 → 森林 → 山地 → 乡村 → 港口 → 隧道 → 工地 → 公园 → 草原 → 太空 → 火山 → 竹林 → 游乐场 → 冰川 → 薰衣草 → 糖果世界 → 霓虹都市 → 樱花小镇 → 极光雪原 → 海底世界 → 灯会 → 循环。

每套风景会配不同天气：城市/沙漠/海边会刮风，雪地会下雪或下冰雹，夜晚和森林可能起雾，山地/乡村/工地/公园/草原/游乐场/薰衣草会刮风，港口有海风或雾，竹林可能下雨，冰川会下雪或刮风，霓虹都市可能起雾，樱花小镇和灯会会刮风，极光雪原会下雪，海底世界可能起雾，雨天有小雨或风雨交加，隧道、太空、火山和糖果世界内没有天气。天气主要影响画面和音效：小雨、风雨、冰雹、下雪、大风都有对应的环境声，风雨天会不定时出现闪电和远处的雷声，雨天路面会出现水洼。这些都不会改变车速或增加难度；再玩一轮后天气也会跟着变化。越往后的关卡要求收集的汉字更多，进度和每关最好成绩会自动保存在本机。

开始页点「选关」可以回到已经通过的任意一关重玩，列表里会显示每关的风景和最好星数。点「重置进度」可以清空关卡进度、最好成绩和识字记录，会先弹窗确认；音量、语速、天气、自建字表等设置不受影响。

## 视角

开始页可以在「平面视角 / 立体视角」之间切换，选择会被记住：

- **平面视角**：原来的俯视画面，三个车道一目了然；车漆加了斜向清漆高光，玻璃有天空反光斜条，车底换成中心深、边缘虚化的柔和阴影，俯视下也有弧面和落地的体积感。
- **立体视角**：真 3D 视角。相机架在小车后上方，用真实的透视投影渲染：天空、远山、地平线、路面和路缘石都按透视收拢。车辆按真实车宽 / 车高 / 车长做成有体积的车：车尾立面、后风挡、尾灯、保险杠、车轮和车顶都在，品牌配色和车标保留；三车道的宽度接近真实道路比例，车道虚线按世界长度排布，近处长、远处短，随透视自然收敛。路上其他车辆、反光柱、路侧景物都有正确的近大远小和接地阴影，由远及近连续滑过。只是画面表现不同，碰撞判定、速度和玩法完全不变，低端手机也能流畅运行。

## 路上的道具

- 🧲 **磁铁**：6 秒内把附近的汉字吸过来（听音选字模式不生效，以免弄乱题目）
- 🛡️ **护盾**：挡住一次碰撞，不减速
- 🚀 **加速**：3 秒冲刺，跑得更快

顶部会显示道具剩余时间。撞车多时游戏会自动放慢一点，连续吃字则稍微加快，尽量照顾不同年龄的小朋友。

## 家长设置

开始页点「家长设置」可以：

- 调整朗读语速（0.6 ~ 1.1 倍）
- 单独关闭背景音乐（不影响朗读）
- 天气效果：关闭 / 弱 / 正常（关闭后不再绘制天气、播放环境音与雷声）
- 粘贴自建字表（每关取其中 12 个；留空使用默认 56 字），也可以一键填入「自然 / 人物 / 常用」分类字表
- 查看学习报告：已学字数、易错字、最近 7 天游玩次数

## 给家长的设计说明

- 没有失败、没有倒计时、没有广告，撞车只有轻微的"呀"提示。
- 按钮和判定框都刻意放大，适合小手操作。
- 右上角 ⏸ 可以暂停；暂停页的「回车库」需要长按 2 秒，防止小朋友误触。切到后台会自动暂停。
- 浏览器返回、手机左右滑返回时会先弹窗确认「要离开游戏吗」，小朋友不会一不小心退出；屏幕中段的左右滑也不会直接退出页面。
- 汉字会尽量出在小车附近；连续 3 秒没吃到字会在正前方补一张，避免一直空跑。
- 连续吃字时两次朗读之间只留很短停顿，听到的读音紧跟刚吃到的汉字，不会越积越慢；录音会提前加载。
- 游戏进行时屏幕常亮（支持的浏览器），不会玩到一半黑屏。
- 吃到汉字、撞到路障有轻微震动反馈（安卓有效，iOS 不支持振动）。
- 声音可以一键静音，音效、汉字朗读和背景音乐一起关掉，设置会被记住。朗读使用系统自带的中文语音（iPhone / 安卓都自带，无需联网）。设备没有中文语音时会提示家长下载，同时界面上仍显示拼音。
- 朗读时背景音乐自动压低，读完恢复，保证小朋友听得清。
- 通关后会生成一张成绩卡，可以保存下来发给家人；结算页会列出本关学到的字，点字可以重听。
- 「我认识的字」里可以一键生成 4 列田字格字卡图片（PNG），方便打印出来复习。
- 听音选字选错的字会被记为「易错字」，下一关会优先安排复习；答对后自动移出。
- 自动适配手机、平板和电脑：竖屏横屏都行，刘海屏安全区域已处理，选过的车会被记住。
- 支持系统的「减少动态效果」设置（减弱抖动动画，雨雪冰雹的粒子也会减少），按钮和文字对比度已加大。

## 添加到主屏幕（像 App 一样玩）

- iPhone / iPad：Safari 打开网页 → 分享 → **添加到主屏幕**
- 安卓：Chrome 打开网页 → 菜单 → **安装应用 / 添加到主屏幕**

添加后会全屏启动、没有地址栏，并且断网也能玩（首次打开后会被缓存）。有新版本时页面底部会自动出现「有新版本啦，点这里更新」，点一下就能换成最新版，不用手动清缓存。

## 本地运行

直接双击 `index.html`，或在目录下启动一个静态服务器：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 文件说明

- `index.html`：游戏本体（单文件，车标图片已内嵌）
- `manifest.json` / `icon-192.png` / `icon-512.png`：添加到主屏幕用的应用信息与图标
- `sw.js`：Service Worker，负责离线缓存
