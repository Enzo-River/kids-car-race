# 小车大冒险 🚗

一个给 5-6 岁小朋友玩的网页版赛车小游戏。无需安装，打开即玩，可添加到手机主屏幕全屏、离线玩。

## 玩法

- 小车自动向前开，按住屏幕下方的 **◀ / ▶** 大按钮左右移动（也可以直接用手指拖动小车，或用键盘方向键 / A、D）。
- 收集路上的 ⭐ 星星，躲开 🚧 路障。撞到路障不会失败，只是会减速并弹开，永远可以继续玩。
- 开到 🏁 终点就通关，会撒彩带庆祝，并给出 1-3 颗星的评价。
- 连续吃到星星时音高会一级级升高，连击越多越"唱"得高。

## 关卡与赛道

每通关一次可以点「下一关」，赛道风景依次轮换：城市 → 沙漠 → 雪地 → 海边 → 循环。越往后的关卡赛道更长、星星更多，进度和每关最好成绩会自动保存在本机。

## 选车

开始前可以在车库里挑一辆车：法拉利 488 GTB、兰博基尼 Aventador、奔驰 G 500、宝马 i8、奥迪 R8、大众甲壳虫、特斯拉 Cybertruck、丰田 86。车身按各车型真实的俯视轮廓绘制（楔形超跑、方盒子大 G、水滴形 i8、圆润甲壳虫、折面 Cybertruck 等），引擎盖上带该品牌的车标，通关后会显示车型名，还可以「换一辆车」。

车标图片取自公开车标素材库，仅用于家庭个人非商业用途；相关商标归各品牌所有，本项目与各品牌无关联。

## 路上的道具

- 🧲 **磁铁**：6 秒内把附近的星星吸过来
- 🛡️ **护盾**：挡住一次碰撞，不减速
- 🚀 **加速**：3 秒冲刺，跑得更快

顶部会显示道具剩余时间。

## 给家长的设计说明

- 没有失败、没有倒计时、没有广告，撞车只有轻微的"呀"提示。
- 按钮和判定框都刻意放大，适合小手操作。
- 右上角 ⏸ 可以暂停；暂停页的「回车库」需要长按 2 秒，防止小朋友误触。切到后台会自动暂停。
- 游戏进行时屏幕常亮（支持的浏览器），不会玩到一半黑屏。
- 吃到星星、撞到路障有轻微震动反馈（安卓有效，iOS 不支持振动）。
- 声音可以一键静音，音效和背景音乐一起关掉，设置会被记住。
- 通关后会生成一张成绩卡，可以保存下来发给家人。
- 自动适配手机、平板和电脑：竖屏横屏都行，刘海屏安全区域已处理，选过的车会被记住。

## 添加到主屏幕（像 App 一样玩）

- iPhone / iPad：Safari 打开网页 → 分享 → **添加到主屏幕**
- 安卓：Chrome 打开网页 → 菜单 → **安装应用 / 添加到主屏幕**

添加后会全屏启动、没有地址栏，并且断网也能玩（首次打开后会被缓存）。

## 本地运行

直接双击 `index.html`，或在目录下启动一个静态服务器：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 文件说明

- `index.html`：游戏本体（单文件，车标图片已内嵌）
- `manifest.json` / `icon-192.png` / `icon-512.png`：添加到主屏幕用的应用信息与图标
- `sw.js`：Service Worker，负责离线缓存
